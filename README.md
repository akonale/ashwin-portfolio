# ashwin-portfolio

Personal site of Ashwin Konale. Plain HTML/CSS/JS, served by GitHub Pages. No build step.

- `index.html` holds the content (hero, services, experience, workbench, contact)
- `style.css` holds the theme: music-app layout with a CRT console accent
- `main.js` draws the generative cover art for each `.cover` element

To use a photo instead of generated art, add `data-img="https://..."` and `data-alt="..."` to a `.cover`.
